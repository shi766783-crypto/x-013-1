# 宠物家 Petcare Home

家庭宠物健康与日程管家，基于 Vue 3 + Vite 构建，纯前端运行。

## 本地运行

```bash
npm install
npm run dev
```

## 已包含

- 宠物档案：种类、品种、性别、出生日期、年龄、体重、绝育、芯片号和照片
- 健康指标：体重、体温、心率记录，Canvas 趋势图和参考区间提示
- 参考区间按种类（狗/猫/兔/鸟/鱼）与品种（如柴犬、金毛、英短）分别配置，健康状态、趋势图参考带、健康榜单达标率共用同一套标准；无参考区间的指标（如鱼类体温）不做正常/异常判定
- 参考区间仅在展示与统计时现算，历史记录只保存原始测量值，修改种类、品种或调整区间都不会改写旧数据
- 疫苗与驱虫：下次日期和提前 7 天提醒
- 用药、喂食、活动记录，以及每日清单和本周活动统计
- 家庭看板、12 项成就徽章、健康榜单
- `localStorage` 本地持久化，不依赖后端

首次打开会载入一组演示数据，新增或修改的数据会自动保存到当前浏览器。
